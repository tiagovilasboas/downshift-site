Downshift documentation

Install, configure and audit Downshift, the deterministic subagent model router. Published from the public repository; each page links to its source on GitHub.

Downshift here is a Go tool for AI coding agents, not the React downshift autocomplete library and unrelated to any car transmission.

Guide

  • Install Downshift: Claude Code, Codex and Cursor hook setup

    Install Downshift and wire its PreToolUse hook into Claude Code, Codex, Cursor and other harnesses: install.sh, setup --dry-run, doctor checks and manual setup.

  • Downshift configuration: state directory and local settings

    Where Downshift keeps its local state, how the state directory is resolved, and how downshift config prints each effective setting and its source.

  • Downshift and Claude Code subagents: when routing can act

    A Claude Code subagent is routable only when its model is not pinned. How the frontmatter model field decides whether Downshift may rewrite that spawn.

  • Downshift session view: subagent tree, reasons and pause

    downshift session shows what Downshift did in one session: a subagent tree with model and cost, why each spawn was routed, and pause and resume.

  • Downshift report: measuring routed versus control spawn cost

    How downshift report measures savings: a small control group of spawns is left unrouted, and routed and control spawns are compared on cost per completed task.

  • Downshift evidence ladder: what each saving figure means

    Five kinds of saving appear around Downshift and they differ: list prices, telemetry estimates, benchmarks, routed versus control, and cost per task.

  • Downshift companions: Headroom and Claude Code mods to pair

    Tools that work next to Downshift, such as the Headroom compression proxy and Claude Code mods: what Downshift detects, records and never does for them.

  • Downshift offline simulation: routing without model calls

    An offline simulation replays synthetic spawns through the real hook path of four harnesses and fails CI when a savings accounting rule breaks.
