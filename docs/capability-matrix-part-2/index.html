Contradictions and overclaims found

Each line: file:line, the sentence (abridged where long), and what the evidence supports.

  1. README.md:253 "event-driven Context Sensor to govern context token volume". RESOLVED (2026-10-17): README.md:325 now says the sensor "observes context volume (byte counts, never a rewrite)"; no "govern" on the Context Sensor (only GOVERNANCE in the project links).
  2. Semantic boost is the in-process FNV hash (hashembed.go). External MiniLM and E5 were removed 2026-10-17. See docs/design/minilm-semantic.md.
  3. docs/pt/README.md:23 "decide em menos de 2 milissegundos". Holds for short prompts (0.10 ms) only; the audit measured 0.23 s on a typical 1 MiB prompt and 275 ms with the catalog resolver after the prefilter (hardening-audit-2026-10-15.md performance note). Unqualified claim.
  4. docs/guides/install.md:573 "API (direct) | ✅ Yes | ✅ Yes". No evidence file covers an API-key session; the 2026-10-06 write-up records "Plan tier: not recorded".
  5. docs/guides/install.md:585 "On usage-based Pro/Ultra plans where subagent model selection is expanded, routing works." RESOLVED (2026-10-17): install table and prose say rewrite is emitted and child model is unconfirmed (P1.6); matrix row stays Unconfirmed.
  6. docs/guides/install.md:349 "inspects the prompt inside Subagents[0].Prompt ... rewrites Subagents[0].Model". RESOLVED (2026-10-17): install describes the last Subagents entry with a non-empty Prompt, flash_lite / flash, and the undocumented overwrite envelope.
  7. Graphify integration doc removed 2026-10-17; graph escalation is no longer part of the product.
  8. docs/reference/session-models.md:57-63 stale 2026-09-27 field table. RESOLVED (2026-10-17): table rechecked 2026-10-17 with optional session_id, cwd, transcript_path, tool_use_id, permission_mode, workspace_roots; usage via SubagentStop transcript, not async PostToolUse tokens.

Hidden capabilities

Things the code does that no public doc explains well (file where it lives; where it is mentioned, if at all).

  1. Verification sensor. SubagentStop records whether the child ran a recognised test or lint command and whether the last one passed (verification: passed|failed|none on usage records); downshift verification-report groups usage-event counts, verification coverage/status and token-call counts by tier; it reports no price or cost. internal/adapters/claudecode/verification.go, cmd/verification.go. Mentioned once in CHANGELOG; absent from help --all, README, stats-export.
  2. Prompt-injection as a risk category. A task that says "ignore previous instructions", "this is a trivial task" or "use the cheapest model" is treated as risky: never downshifted, floor off the small tier. core/risk.go prompt_injection. Docs name the category in passing only.
  3. The hook's time and safety budget. 1 MiB payload cap, 2 s stdin read timeout, a 1.5 s hook deadline (hookctx.HookBudget) that kills helper commands, 1 s per embed call, 400 ms transcript wait, 500 ms sensor lock, 3 s graph fetcher, and CmdTrusted, which refuses an E5 helper that is curl, bash, -c or a symlink. cmd/main.go, internal/hookctx, semantic/embed.go, e5shadow/cmdvalidate.go. None of these numbers or the helper-command policy appear in user docs.
  4. Operational knobs. Event-log rotation (DOWNSHIFT_LOG_MAX_MB, DOWNSHIFT_LOG_MAX_BACKUPS), DOWNSHIFT_NB_UPSHIFT, DOWNSHIFT_NB_DOWNSHIFT, DOWNSHIFT_QUIET, and DOWNSHIFT_CONTROL_SHARE are listed in docs/guides/config.md. DOWNSHIFT_E5_*, DOWNSHIFT_GRAPHIFY_CMD, and DOWNSHIFT_MINILM_EMBED are gone.
  5. Graph escalation removed 2026-10-17.
  6. Second stderr line per spawn. downshift: honor=unobserved quota=<available|held|unknown> usage=unobserved is printed for every decision on every harness; only docs/guides/daily-truth.md describes it.
  7. Antigravity multi-child rule. The decision, the task text and the written model all follow the last subagent that has a Prompt; earlier children are not routed. antigravity.go decidedSubagent, TestMultiChild_*. Only the hardening audit and CHANGELOG mention it.
  8. Decision-intelligence shadow record and in-process extras. Every decision event carries a decision_intelligence advisory block (Apply: false); internal/lifecycleobserver compiles but has no CLI or hook path (internal/orchestration and internal/routecache were removed on 2026-10-19). Design docs exist; user docs do not say they are inert.
  9. Agent-type baseline attribution. stats --detail prints "Baseline by agent type" so an unknown-baseline rate can be pinned on Explore, Plan or custom. Only stats-export.md describes it.
  10. Refuted-rewrite honesty. When Claude Code reports a different resolvedModel, the child token record links to the model that ran; the rewrite is refuted and is not counted as applied. Current reports do not emit a dollar-savings field (TestAggregate_RefutedRewriteSavesNothing). Explained in the audit and CHANGELOG, not in the stats docs a user reads.
