Send the code a change touches, not the whole repo.

Code intelligence is opt-in (downshift dci enable). For a symbol, it finds the impact radius: the callers a change can reach. It then packs only the affected symbols under a byte cap, so the agent starts with the relevant code.

files indexed, files selected, for the query "where is the tier floor applied"
1,869 bytes
packed output, inside the default 3500-byte budget (range 512 to 16384)
5 ms
retrieval, after a 402 ms index build. Packing took 0 ms.

That run selected 8 symbols from 480 candidates. It supports Go through the AST, and TypeScript, JavaScript, Python, Rust, PHP, Java and C# by pattern. Two modes: active injects the context, observe only records telemetry.

What is measured so far: latency and bytes. What is not: answer quality. Treat it as a way to send less, not as proof of better answers.

Know what a cold cache costs before you pay it.

A cold prompt cache makes the next send expensive. The cache-tax mod (Claude Code 2.1.287 or later) prices it first. A cold send on a context of 50k or more is held once, with its estimated rewrite price, so you decide.

  1. /keepwarm
  3. warmcache hit
  4. idleno requests
  5. coldcache gone
  6. heldsend held once

/keepwarm

/keepwarm keeps the cache alive through a break. Warming spends usage, so it is a choice, not a default.

The honest limit of output compaction

In Claude Code, a hook cannot rewrite tool output in flight. The native provider measures bytes and saves no tokens there. Real in-flight compression needs a proxy such as Headroom. Downshift detects and records it. It never starts it.

Stay in control.

A router that saves money is only useful if it never gambles with your work. These are the rules it follows.

  • Local classification

    Each task is scored on your machine with signals and a model catalog. No LLM call. Prompts are evaluated in memory and never stored.

  • Fail-open

    Any error or missing capability leaves the spawn untouched. Downshift only changes the model and effort fields.

  • Doubt keeps your model

    Unsure? The spawn keeps the model it asked for. Doubt never spends money, and a cheaper pick without confidence is held.

  • Risk floors

    Payments, auth and secrets are protected. Migrating a payment webhook stayed on opus. Rotating production secrets was held.

Downshift: the optimization layer for AI coding agents.

Why Downshift

Coding agents hand renames, test runs and file listings to subagents that often inherit the priciest model. They also load more code context than the task needs. That is where Claude Code token optimization starts.

Downshift is harness engineering for that gap. A local hook scores each delegated task and picks a model and effort from a catalog. Optional code intelligence sends only the affected symbols. Risk floors protect auth, payments and secrets. Doubt keeps the requested model.

Not the React libraryUnrelated to the React downshift autocomplete library. This is a Go tool for AI coding agents, not a UI component.

Frequently asked questions

Does Downshift call an LLM to pick a model?

No. Routing uses scored signals and a model catalog, locally. No extra tokens and no extra model call in the spawn path.

What happens when Downshift is unsure?

The spawn keeps the model it asked for. Doubt never spends money. Downshift is also fail-open: any error or missing capability leaves the spawn untouched.

Which coding agents does it support?

Claude Code is verified. Codex and Cursor are functional. OpenCode is beta. Antigravity and KiroCrew are experimental. The harness matrix in the docs states what was actually observed for each.

How much does it save?

In one controlled Claude Code trial, mechanical delegated tasks cost about 12% less at list price, with 12 of 12 validated checks passing. On natural use, no saving is attributable yet. Estimates are not invoices.

How do I reduce Claude Code token usage and costs?

Start with delegated subagent work. Downshift routes mechanical subagent tasks to a cheaper tier through a PreToolUse hook, prices a cold prompt cache before you pay for it, and can pack relevant code context. It is not a token compressor. Estimates are not invoices.

How do I route subagents to cheaper models?

Run the install script, then downshift setup. It adds a hook that scores each subagent spawn and rewrites the model, and the effort where the harness supports it, when it is confident. Risk floors protect auth, payments and secrets. Doubt keeps the original model.

Is Downshift related to the React downshift library?

No. The React downshift library builds accessible autocomplete and dropdown components. This project is an unrelated Go tool that routes AI coding agent subagents to right-sized models.

Is it free?

Yes. Apache-2.0, a single Go binary, no daemon.

Does it change my workflow?

No. You keep using your harness as before. Downshift runs as a hook when a subagent starts and changes only the model and effort fields. Errors leave the spawn untouched. Code intelligence is opt-in.
