Why Downshift

Claude Code token optimization is mostly a routing problem. Parents delegate renames, test runs and file listings to subagents that often inherit the most expensive model and the highest reasoning effort.

Downshift is harness engineering for that gap. A native hook scores each delegated task with local signals and picks a model and effort from a catalog. Risk floors protect auth, payments and secrets. Doubt keeps the requested model.

Not the React libraryUnrelated to the React downshift autocomplete library. This is a Go tool for AI coding agents, not a UI component.

Frequently asked questions

Does Downshift call an LLM to pick a model?

No. Routing uses scored signals and a model catalog, locally. No extra tokens and no extra model call in the spawn path.

What happens when Downshift is unsure?

The spawn keeps the model it asked for. Doubt never spends money. Downshift is also fail-open: any error or missing capability leaves the spawn untouched.

Which coding agents does it support?

Claude Code is verified. Codex and Cursor are functional. OpenCode is beta. Antigravity and KiroCrew are experimental. The harness matrix in the docs states what was actually observed for each.

How much does it save?

In one controlled Claude Code trial, mechanical delegated tasks cost about 12% less at list price, with 12 of 12 validated checks passing. On natural use, no saving is attributable yet. Estimates are not invoices.

How do I reduce Claude Code token usage and costs?

Start with delegated subagent work. Downshift routes mechanical subagent tasks to a cheaper tier through a PreToolUse hook, prices a cold prompt cache before you pay for it, and can pack relevant code context. Estimates are not invoices.

How do I route subagents to cheaper models?

Run the install script, then downshift setup. It adds a hook that scores each subagent spawn and rewrites the model, and the effort where the harness supports it, when it is confident. Risk floors protect auth, payments and secrets. Doubt keeps the original model.

Is Downshift related to the React downshift library?

No. The React downshift library builds accessible autocomplete and dropdown components. This project is an unrelated Go tool that routes AI coding agent subagents to right-sized models.

Is it free?

Yes. Apache-2.0, a single Go binary, no daemon.
