Guia rápido de custo do Claude Code: settings, variáveis e comandos

Downshift por Tiago Vilas Boas. Atualizado em 24 de outubro de 2026

Este Downshift é uma ferramenta em Go para agentes de código com IA, não a biblioteca React downshift de autocomplete.

Resumo

As maiores alavancas de custo são /clear entre tarefas, o modelo certo para cada trabalho, um modelo mais barato para subagentes mecânicos, esforço menor e uma janela de autocompactação menor. Esta página lista o comando, a chave de settings ou a variável exata de cada uma, com a seção da doc que a define, e mostra a única escolha que a doc deixa manual: o modelo do subagente por tarefa.

Todas as alavancas de custo do Claude Code que a Anthropic documenta, em tabelas, cada uma com link para a seção da doc. O que não está na documentação oficial ficou de fora.

Verificado em 2026-10-24 em code.claude.com/docs. Nomes, padrões e versões mínimas mudam entre releases; confirme na página linkada.

Quais comandos do Claude Code mudam o custo?

Comandos e atalhos que mudam o que você envia, qual modelo responde ou quanto contexto fica.

NomeEfeitoDoc
/usageUso de tokens e custo estimado da sessão, a linha Prompt cache (main) e, em plano, o detalhamento com recomendações.costs: /usage
/clearComeça do zero. A doc manda usar ao trocar para trabalho não relacionado, porque contexto velho gasta tokens em toda mensagem seguinte.costs: contexto
/compact [instruções]Resume a conversa. Instruções como 'Focus on code samples and API usage' guiam o que fica. Em contexto grande, é uma requisição grande.costs: contexto
/contextMostra o que ocupa espaço de contexto, por exemplo a listagem de ferramentas de MCP.costs: MCP
/model [alias|nome]Troca o modelo no meio da sessão. Sem argumento, abre o seletor. Cada modelo tem seu cache, então a troca relê o histórico sem cache.model-config
/effort [nível|auto]Define o nível de esforço. Esforço menor em tarefa simples reduz tokens de raciocínio, cobrados como saída.model-config: esforço
/autocompact [tamanho|auto]Define a janela de autocompactação do modelo atual.model-config: autocompactação
/mcpLista os servidores MCP configurados para você desligar os que não usa.costs: MCP
/rewindVolta conversa e código a um checkpoint anterior. O rewind aproveita uma entrada de cache antiga em vez de montar um prefixo novo.prompt-caching: rewind
/insightsGera um relatório HTML sobre como você trabalha, a partir de sessões recentes. A análise em si consome tokens.costs: insights
Shift+TabPassa para o modo de plano: o Claude propõe a abordagem antes de editar.costs: tarefas complexas

Coloque no shell ou no bloco env do settings.json. A lista completa está na página de variáveis de ambiente oficial.

Como definir o modelo do subagente no Claude Code?

Segundo a doc, o Claude Code escolhe o modelo do subagente nesta ordem: o modelo que o Claude passa naquela chamada, depois o model do frontmatter do agente (inherit é o modelo principal), depois CLAUDE_CODE_SUBAGENT_MODEL e por fim o modelo da conversa principal. Antes da v2.1.251, a variável vinha primeiro.

NomeEfeitoDoc
model: haikuCampo do frontmatter na definição do agente. Aceita sonnet, opus, haiku, fable, um ID completo ou inherit. A página de custos sugere haiku para tarefas simples de subagente.sub-agents: escolher o modelo
model: inheritUsa o modelo da conversa principal.sub-agents: escolher o modelo
Agente chamado ExploreUm agente de usuário ou de projeto com esse nome e model: haiku substitui o Explore embutido, que de outro modo segue o modelo principal.sub-agents: escolher o modelo
Bloco env com forceDefina CLAUDE_CODE_SUBAGENT_MODEL e CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 para rodar todo subagente num modelo só. Definir só a primeira não muda o Explore nem o Plan embutidos.sub-agents: um modelo só

Quais hábitos reduzem o custo por tarefa no Claude Code?

Da página de custos, na ordem que costuma pesar mais.

NomeEfeitoDoc
Rode testes focados, não a suíte inteiraPeça o arquivo ou o nome do teste. Testar em incrementos pega problema cedo, e a saída longa fica fora do contexto.costs: tarefas complexas
Modelo menor para subagente mecânicoRenomear, formatar e localizar arquivo raramente pedem o modelo principal. Use model: haiku no agente ou CLAUDE_CODE_SUBAGENT_MODEL.costs: modelo certo
Delegue o trabalho verbosoTestes, busca em docs e leitura de log voltam como resumo e a saída fica no contexto do subagente. As requisições do subagente ainda consomem seu uso.costs: subagentes
Escreva prompts específicosCitar o arquivo e a função evita varredura ampla.costs: prompts
Planeje antes em tarefa complexaO modo de plano evita retrabalho caro quando a primeira direção está errada.costs: tarefas complexas
Mantenha o CLAUDE.md curtoEle carrega em toda abertura de sessão. Mova instruções de fluxo específico para skills, que carregam sob demanda. A doc mira menos de 200 linhas.costs: skills
Escolha modelo e esforço uma vezTrocar o modelo ou, na maioria dos modelos, o esforço no meio da sessão faz a próxima requisição reler o histórico inteiro sem cache.prompt-caching: troca de modelo

O que o Downshift acrescenta a essas settings?

Tudo acima é manual e não usa software extra. O Downshift automatiza a escolha que as tabelas deixam com você e mantém os números honestos.

ParteO que fazEvidência e limites
Roteamento por subagenteUm hook PreToolUse pontua cada tarefa delegada localmente e reescreve o modelo do subagente, só quando tem confiança. Na dúvida, mantém o modelo pedido. Nenhum LLM roda no loop de roteamento.Bateria de quatro braços em 2026-10-21, tarefas mecânicas delegadas, 46 execuções, um operador: cerca de 24% menos tokens por tarefa aceita com roteamento (16% por execução; intervalo de 95% de +2,1% a +46,7%). Não demonstrado em tarefas complexas naturais.
Compactordownshift compact -- <comando> reduz a saída de testes e builds da lista permitida ao resumo de passou ou falhou e mantém o código de saída real.Corpus de compactação de 2026-10-21, fixtures sintéticas: 82,3% menos bytes nos 26 de 248 arquivos que compactam, 23,7% nos 248. Bytes, não tokens de LLM.
DCI (opt-in)Empacota só o código que a mudança toca, dentro de um orçamento em bytes.Desligado até você ativar. Latência e tamanho da saída são medidos; a qualidade da resposta não foi validada.

Números completos: arquivo de evidência dos quatro braços. Um operador, tarefas mecânicas: trate como medição, não como garantia.

Perguntas frequentes

Qual a forma mais rápida de reduzir o custo do Claude Code?

Rode /usage para ver onde os tokens vão, use /clear entre tarefas não relacionadas, escolha Sonnet ou Haiku onde o Opus não é necessário e baixe o esforço em trabalho simples. Defina model: haiku em subagentes que fazem tarefas mecânicas. Tudo isso está na página de custos da Anthropic.

Qual variável de ambiente define o modelo do subagente?

CLAUDE_CODE_SUBAGENT_MODEL define um padrão para os subagentes. Desde a v2.1.251, ela fica abaixo do modelo que o Claude passa na chamada e do model do frontmatter do agente. Some CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 (v2.1.257 ou superior) para ela vencer todas as fontes.

Como faço a autocompactação disparar mais cedo?

Defina CLAUDE_AUTOCOMPACT_PCT_OVERRIDE com um percentual de 1 a 100; ela só consegue baixar o limite. Ou ajuste a janela direto com CLAUDE_CODE_AUTO_COMPACT_WINDOW, a chave autoCompactWindow ou /autocompact.

Trocar de modelo ou de esforço no meio da sessão custa mais?

Custa. Cada modelo tem seu cache, então o /model faz a próxima requisição reler o histórico inteiro sem cache. Na maioria dos modelos a troca de esforço também; a doc diz que Opus 5.5, Sonnet 5.5, Haiku 5.5 e Fable 5.1 mantêm o cache com chave de API ou assinatura.

Toda variável desta página está na doc oficial?

Está. O que não apareceu em code.claude.com/docs ficou de fora, e cada linha linka a sua seção. Verificado em 2026-10-24. Padrões e versões mínimas mudam, então confirme no link antes de depender de uma delas.

O Downshift substitui essas settings?

Não. Ele acrescenta roteamento do modelo do subagente por tarefa e compactação de saída por cima delas. O ganho medido é de cerca de 24% menos tokens por tarefa aceita em tarefas mecânicas delegadas (46 execuções, um operador, 2026-10-21), e não foi testado combinado com as outras alavancas.

Instalar o Downshift

Rode downshift setup --dry-run antes para ver cada mudança. downshift setup --undo restaura seus backups.

curl -fsSL https://raw.githubusercontent.com/tiagovilasboas/downshift/main/install.sh | sh && downshift setup

Plugin do Claude Code

/plugin install downshift --marketplace tiagovilasboas/downshift
