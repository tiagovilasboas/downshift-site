Guias de Claude Code

Como o Claude Code gasta tokens e como gastar menos: o que a Anthropic documenta, o que o Downshift mediu e o que ainda ninguém mediu.

Este Downshift é uma ferramenta em Go para agentes de código com IA, não a biblioteca React downshift de autocomplete.

  • Como economizar tokens no Claude Code, sem mito

    Como gastar menos tokens no Claude Code: modelo, subagentes, cache de prompt e contexto. O que a documentação da Anthropic afirma e o que não está provado.

  • Qual modelo cada subagente usa no Claude Code

    Como o Claude Code escolhe o modelo de um subagente: parâmetro da chamada, frontmatter, CLAUDE_CODE_SUBAGENT_MODEL e modelo da sessão. Precedência e exemplo.

  • O limite de uso do Claude Code acaba rápido: de onde vem o consumo

    Por que o limite de 5 horas e o semanal do Claude Code acabam rápido: subagentes, cache frio, contexto longo. Como medir e o que ajustar, segundo a Anthropic.
