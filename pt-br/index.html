Envie o código que a mudança toca, não o repositório inteiro.

A inteligência de código é opt-in (downshift dci enable). Para um símbolo, ela calcula o raio de impacto: os chamadores que uma mudança pode alcançar. Depois empacota só os símbolos afetados, dentro de um limite de bytes, e o agente já começa com o código relevante.

Essa execução selecionou 8 símbolos entre 480 candidatos. Há suporte a Go por AST e a TypeScript, JavaScript, Python, Rust, PHP, Java e C# por padrões de texto. Dois modos: active injeta o contexto, observe só registra telemetria.

O que foi medido até agora: latência e bytes. O que não foi: qualidade das respostas. Veja isso como uma forma de enviar menos, não como prova de respostas melhores.

Saiba quanto custa um cache frio antes de pagar.

Um prompt cache frio deixa o próximo envio caro. O mod cache-tax (Claude Code 2.1.287 ou superior) calcula esse preço antes. Um envio frio em um contexto de 50k ou mais fica retido uma vez, com o preço estimado da reescrita, e a decisão é sua.

/keepwarm

O /keepwarm mantém o cache vivo durante uma pausa. Manter aquecido gasta uso, então é uma escolha, não um padrão.

O limite real da compactação de saída

No Claude Code, um hook não consegue reescrever a saída de uma ferramenta durante a execução. O provider nativo mede bytes e não economiza tokens aí. Compressão real em trânsito exige um proxy, como o Headroom. O Downshift detecta e registra o proxy. Nunca o inicia.

Mantenha o controle.

Um roteador que economiza só serve se nunca apostar com o seu trabalho. Estas são as regras que ele segue.

  • Classificação local

    Cada tarefa é pontuada na sua máquina, com sinais e um catálogo de modelos. Sem chamada de LLM. Os prompts são avaliados em memória e nunca guardados.

  • Fail-open

    Qualquer erro ou capacidade ausente deixa o subagente intacto. O Downshift só altera os campos de modelo e de esforço.

  • Na dúvida, o seu modelo

    Sem certeza? O subagente mantém o modelo que pediu. Dúvida nunca gasta dinheiro, e uma escolha mais barata sem confiança fica retida.

  • Pisos de risco

    Pagamentos, autenticação e segredos são protegidos. A migração de um webhook de pagamento ficou no opus. A rotação de segredos de produção foi retida.

Downshift: a camada de otimização para agentes de código com IA.

Por que o Downshift

Agentes de código entregam renomeações, execuções de teste e listagens de arquivos a subagentes que muitas vezes herdam o modelo mais caro. Eles também carregam mais contexto de código do que a tarefa pede. É aí que começa a otimização de tokens no Claude Code.

O Downshift é harness engineering para essa lacuna. Um hook local pontua cada tarefa delegada e escolhe modelo e esforço em um catálogo. A inteligência de código, opcional, envia só os símbolos afetados. Pisos de risco protegem autenticação, pagamentos e segredos. Na dúvida, vale o modelo pedido.

Não é a biblioteca ReactSem relação com a biblioteca React downshift de autocomplete. Esta é uma ferramenta em Go para agentes de código com IA, não um componente de interface.

O que melhora
Em qual modelo cada subagente roda e qual contexto de código ele recebe.
Por que confiar
As decisões rodam na sua máquina. Na dúvida, vale o seu modelo. Há um teste controlado publicado.
Como começar
Um script e um comando de configuração. Depois, abra uma sessão nova.

Para quem é

  • Devs que delegam a subagentes no Claude Code, Codex ou Cursor e acompanham a conta de tokens.
  • Times que constroem um harness de agentes de código e precisam de roteamento de modelos determinístico e auditável.
  • Mantenedores que preferem resultados medidos, com grupo de controle, a promessas de fornecedor.

Mods para o Claude Code

Painéis e botões pequenos ao redor da sua sessão. Nenhum deles tem lógica de roteamento. No Claude Code, o downshift setup instala savvy-progress, filetree e downshift-dock.

  • savvy-progressUma barra de progresso e um painel /agents-info com os seus subagentes.
  • filetreeUm painel de árvore de arquivos para a sessão.
  • downshift-dockUma linha acima do prompt, com botões que trazem de volta os painéis Files e Agents.
  • cache-taxCalcula o preço de um prompt cache frio antes de você pagar e adiciona o /keepwarm.
  • downshift-themeTemas escuro e claro opcionais, em preto, branco e cinza. O setup não os instala.

Perguntas frequentes

O Downshift chama um LLM para escolher o modelo?

Não. O roteamento usa sinais pontuados e um catálogo de modelos, localmente. Sem tokens extras e sem chamada de modelo extra ao criar o subagente.

O que acontece quando o Downshift não tem certeza?

O subagente mantém o modelo que pediu. Dúvida nunca gasta dinheiro. O Downshift também é fail-open: qualquer erro ou capacidade ausente deixa o subagente intacto.

Quais agentes de código ele suporta?

O Claude Code é verificado. Codex e Cursor são funcionais. OpenCode é beta. Antigravity e KiroCrew são experimentais. A matriz de harnesses na documentação diz o que foi de fato observado em cada um.

Quanto ele economiza?

Em um teste controlado no Claude Code, tarefas mecânicas delegadas custaram cerca de 12% menos a preço de tabela, com 12 de 12 verificações validadas passando. No uso natural, nada é atribuível ainda. Estimativas não são faturas.

Como reduzir o uso de tokens e o custo do Claude Code?

Comece pelo trabalho delegado a subagentes. O Downshift roteia tarefas mecânicas para uma faixa mais barata por um hook PreToolUse, calcula o custo de um prompt cache frio antes de você pagar e pode empacotar só o contexto relevante. Ele não é um compressor de tokens. Estimativas não são faturas.

Como rotear subagentes para modelos mais baratos?

Rode o script de instalação e depois downshift setup. Ele adiciona um hook que pontua cada subagente e, com confiança, reescreve o modelo e o esforço, onde o harness permite. Pisos de risco protegem autenticação, pagamentos e segredos. Na dúvida, o modelo original fica.

O Downshift tem relação com a biblioteca React downshift?

Não. A biblioteca React downshift cria componentes acessíveis de autocomplete e dropdown. Este projeto é uma ferramenta em Go, sem relação, que roteia subagentes de agentes de código com IA para modelos do tamanho certo.

É grátis?

Sim. Apache-2.0, binário único em Go, sem daemon.

O Downshift muda o meu fluxo de trabalho?

Não. Você continua usando o seu harness como antes. O Downshift roda como um hook quando um subagente começa e altera só os campos de modelo e de esforço. Erros deixam o subagente intacto. A inteligência de código é opt-in.
