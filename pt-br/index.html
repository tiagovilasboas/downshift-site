Otimização open source de tokens para o seu harness de agentes de código: roteie subagentes para o modelo certo, mantenha o prompt cache aquecido, empacote só o contexto relevante e meça o que realmente importa. Determinístico, sem LLM no caminho, fail-open, um único binário em Go.

Como funciona a otimização de tokens

Quatro capacidades atrás de um único downshift setup, rodando como hooks nativos dentro do seu harness.

Roteamento determinístico de modelos

Quando o agente pai delega peças mecânicas pequenas, como renomeações, testes e listagens, elas recebem uma faixa mais barata. Pisos de risco protegem autenticação, pagamentos e segredos.

Dúvida nunca gasta dinheiro

Quando o classificador não tem certeza, o subagente mantém o modelo que pediu. Subir de faixa exige confiança.

Higiene do prompt cache

Calcula o custo de um prompt cache frio antes de você pagar e oferece /keepwarm durante uma pausa.

Contexto enxuto

Índice opcional de AST e grafo de chamadas que empacota só os símbolos afetados, dentro de um limite de bytes.

Subagente certomodelo e esforço

Otimizar tokens no Claude Code é, em grande parte, um problema de roteamento. Agentes de código entregam trabalho mecânico, como renomeações, execuções de teste e listagens de arquivos, a subagentes que muitas vezes herdam o modelo mais caro e o maior esforço de raciocínio.

O Downshift é harness engineering para essa lacuna. Ele roda como um hook nativo, pontua cada tarefa delegada com sinais locais e escolhe modelo e esforço do tamanho certo a partir de um catálogo. Na dúvida, o subagente mantém o modelo que pediu.

Não é a biblioteca React. Este Downshift não tem relação com a biblioteca React downshift de autocomplete e dropdown. É uma ferramenta em Go para agentes de código com IA, não um componente de interface.

Para quem é

  • Devs que usam Claude Code, Codex ou Cursor, delegam trabalho a subagentes e acompanham a conta de tokens.
  • Times que constroem um harness de agentes de código e querem roteamento de modelos determinístico e auditável.
  • Mantenedores que querem resultados medidos, com grupo de controle, no lugar de promessas de fornecedor.

Um roteador para todo harness de agentes de código

Para engenheiros de harness

Todo harness usa o mesmo roteador. Os adaptadores só leem o payload, declaram suas capacidades e emitem a resposta no formato do harness. Escolha um harness para ver o hook que ele usa. O comportamento vive em camadas compartilhadas; os adaptadores só leem e emitem. O status é o verificado, não o desejado.

Medido, não prometido

Estimativas não são faturas. O Downshift deixa cerca de 1 em cada 10 subagentes sem rotear, como grupo de controle, para que o downshift report compare roteado e controle. Os prompts são avaliados em memória e nunca armazenados. No uso natural e complexo, nada é atribuível ainda, e a documentação diz isso.

  • Roteamento em resumo
  • Na dúvida, nada muda
  • Um roteador, todo harness

Perguntas frequentes

O que acontece quando o Downshift não tem certeza?

O subagente mantém o modelo que pediu. Dúvida nunca gasta dinheiro, e o Downshift é fail-open.

Quais agentes de código ele suporta?

O Claude Code é verificado; Codex e Cursor são funcionais; OpenCode é beta; Antigravity e KiroCrew são experimentais.

O Downshift chama um LLM para escolher o modelo?

Não. Sinais pontuados e um catálogo, localmente, em milissegundos. Sem tokens extras ao criar o subagente.

Quanto ele economiza?

Cerca de 12% a preço de tabela em trabalho mecânico delegado, em um teste controlado no Claude Code. Trate como estimativa.

Como reduzir o uso de tokens no Claude Code?

O trabalho delegado a subagentes é um lugar comum de gasto excessivo. O Downshift roteia tarefas mecânicas de subagentes para uma faixa de modelo mais barata por um hook PreToolUse, avisa antes de você pagar por um prompt cache frio e pode empacotar só o contexto de código relevante. Em um teste controlado, tarefas mecânicas delegadas economizaram cerca de 12% a preço de tabela. Estimativas não são faturas.

Como rotear subagentes para modelos mais baratos?

Instale o Downshift com o script de instalação e rode downshift setup. Ele adiciona um hook que pontua cada subagente criado e reescreve o modelo e o esforço de raciocínio quando tem confiança. Pisos de risco protegem autenticação, pagamentos e segredos, e a dúvida mantém o modelo original.

O Downshift tem relação com a biblioteca React downshift?

Não. A biblioteca React downshift cria componentes acessíveis de autocomplete e dropdown. Este projeto é uma ferramenta em Go, sem relação, que roteia subagentes de agentes de código com IA para modelos do tamanho certo.

É grátis?

Sim. Apache-2.0, binário único em Go, sem daemon.
