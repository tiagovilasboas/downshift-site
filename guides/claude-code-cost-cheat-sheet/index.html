Claude Code cost cheat sheet: settings, env vars and commands

Downshift by Tiago Vilas Boas. Updated 24 October 2026

Downshift here is a Go tool for AI coding agents, not the React downshift autocomplete library and unrelated to any car transmission.

TL;DR

The biggest cost levers are /clear between tasks, the right model per job, a cheaper model for mechanical subagents, a lower effort level and a smaller auto-compact window. This page lists the exact command, settings key or variable for each, with the doc section that defines it, then shows the one gap the docs leave manual: choosing the subagent model per task.

Every cost lever in Claude Code that Anthropic documents, in tables, each with a link to the doc section. Names that are not in the official docs are not listed.

Checked on 2026-10-24 against code.claude.com/docs. Names, defaults and minimum versions change between releases, so confirm with the linked page.

Which Claude Code commands change cost?

Slash commands and shortcuts that change what you send, which model answers or how much context stays.

NameEffectDocs
/usageSession token use and estimated cost, the Prompt cache (main) line, and on a plan the usage breakdown with recommendations.costs: /usage
/clearStarts fresh. The docs say to use it when you switch to unrelated work, because stale context wastes tokens on every later message.costs: manage context
/compact [instructions]Summarizes the conversation. Instructions such as 'Focus on code samples and API usage' steer what is kept. It is itself a large request on a big context.costs: manage context
/contextShows what is consuming context space, for example MCP tool listings.costs: MCP overhead
/model [alias|name]Switches the model mid-session. With no argument it opens the picker. Each model has its own cache, so a switch reads the history uncached.model-config
/effort [level|auto]Sets the effort level. Lower effort for simple tasks reduces thinking tokens, which are billed as output.model-config: effort
/autocompact [size|auto]Sets the auto-compact window for the current model.model-config: auto-compact
/mcpLists configured MCP servers so you can disable the ones you do not use.costs: MCP overhead
/rewindRestores conversation and code to an earlier checkpoint. Rewinding hits an earlier cache entry instead of building a new prefix.prompt-caching: rewind
/insightsWrites an HTML report on how you work from recent sessions. The analysis itself uses tokens.costs: insights
Shift+TabCycles to plan mode so Claude proposes an approach before it edits.costs: complex tasks

How do I set the subagent model in Claude Code?

Claude Code picks a subagent's model in this order, per the docs: the model Claude passes for that call, then the agent's model frontmatter (where inherit means the main model), then CLAUDE_CODE_SUBAGENT_MODEL, then the main conversation's model. Before v2.1.251 the variable came first.

NameEffectDocs
model: haikuFrontmatter field in an agent definition. Accepts sonnet, opus, haiku, fable, a full model ID or inherit. The cost page suggests haiku for simple subagent tasks.sub-agents: choose a model
model: inheritUses the main conversation's model.sub-agents: choose a model
Agent named ExploreA user or project agent with that name and model: haiku replaces the built-in Explore, which otherwise follows the main model.sub-agents: choose a model
Env block with forceSet CLAUDE_CODE_SUBAGENT_MODEL and CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 to run every subagent on one model. Setting the first alone does not change the built-in Explore or Plan.sub-agents: one model

Which habits cut Claude Code cost per task?

From the cost page, in the order that tends to matter.

NameEffectDocs
Run focused tests, not the whole suiteAsk for the one test file or test name. Incremental testing catches problems early, and long output stays out of context.costs: complex tasks
Smaller model for mechanical subagentsRenames, formatting and file lookups rarely need the main model. Use model: haiku on the agent, or CLAUDE_CODE_SUBAGENT_MODEL.costs: right model
Delegate verbose workTests, doc fetches and log reading return a summary while the output stays in the subagent's context. The subagent's own requests still draw on your usage.costs: subagents
Write specific promptsNaming the file and function avoids broad scanning.costs: prompts
Plan first on complex workPlan mode prevents expensive rework when the first direction is wrong.costs: complex tasks
Keep CLAUDE.md shortIt loads at every session start. Move workflow-specific instructions to skills, which load on demand. The docs aim for under 200 lines.costs: skills
Pick model and effort onceChanging the model or, on most models, the effort mid-session makes the next request read the whole history uncached.prompt-caching: switching

What does Downshift add to these settings?

Everything above is manual and uses no extra software. Downshift automates the one choice the tables leave to you, and it keeps the numbers honest.

PartWhat it doesEvidence and limits
Per-subagent routingA PreToolUse hook scores each delegated task locally and rewrites the subagent's model, only when confident. Doubt keeps the model you asked for. No LLM runs in the routing loop.Four-arm battery 2026-10-21, mechanical delegated tasks, 46 runs, one operator: about 24% fewer tokens per accepted task with routing (16% per run; 95% interval +2.1% to +46.7%). Not shown on natural complex tasks.
Compactordownshift compact -- <command> cuts allowlisted test and build output to the pass or fail summary and keeps the real exit code.Compaction corpus 2026-10-21, synthetic fixtures: 82.3% fewer bytes on the 26 of 248 files that compact, 23.7% across all 248. Bytes, not LLM tokens.
DCI (opt-in)Packs only the code a change touches, under a byte budget.Off until you enable it. Latency and output size are measured; answer quality is not validated.

Full numbers: four-arm evidence file. One operator, mechanical tasks: treat it as a measurement, not a guarantee.

Frequently asked questions

What is the fastest way to reduce Claude Code cost?

Run /usage to see where tokens go, use /clear between unrelated tasks, pick Sonnet or Haiku where Opus is not needed, and lower the effort level for simple work. Set model: haiku on subagents that do mechanical tasks. All of this is in Anthropic's cost page.

Which environment variable sets the subagent model?

CLAUDE_CODE_SUBAGENT_MODEL sets a default for subagents. Since v2.1.251 it ranks below the model Claude passes for the call and the agent's model frontmatter. Add CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 (v2.1.257 or later) to make it override every source.

How do I make auto-compact trigger earlier?

Set CLAUDE_AUTOCOMPACT_PCT_OVERRIDE to a percentage from 1 to 100; it can only lower the threshold. Or set the window directly with CLAUDE_CODE_AUTO_COMPACT_WINDOW, the autoCompactWindow setting or /autocompact.

Does switching model or effort mid-session cost extra?

Yes. Each model has its own cache, so /model makes the next request read the whole history uncached. On most models a mid-session effort change does too; the docs say Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable 5.1 keep the cache on an API key or subscription.

Is every variable on this page in the official docs?

Yes. Anything not found on code.claude.com/docs was left out, and each row links to its section. Checked on 2026-10-24. Defaults and minimum versions change, so confirm with the link before you rely on one.

Does Downshift replace these settings?

No. It adds per-task subagent model routing and output compaction on top of them. Its measured gain is about 24% fewer tokens per accepted task on mechanical delegated tasks (46 runs, one operator, 2026-10-21), and it was not tested combined with the other levers.

Install Downshift

Run downshift setup --dry-run first to preview every change. downshift setup --undo restores your backups.

curl -fsSL https://raw.githubusercontent.com/tiagovilasboas/downshift/main/install.sh | sh && downshift setup

Claude Code plugin

/plugin install downshift --marketplace tiagovilasboas/downshift
